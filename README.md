Windows releases (.exe) for the open source **Strawberry Music Player**.

These are unofficial Windows releases of Strawberry Music Player. I do not represent the original Strawberry developers or project.

I can't guarantee the functionality of these builds on every system, but I test them on Windows 11 before uploading.
